# Quiz v1

A beginner-friendly Python quiz application that allows users to answer multiple-choice questions and receive their final score.

## Features

- Multiple-choice questions
- User answer input
- Automatic answer checking
- Score calculation
- Simple command-line interface

## How It Works

1. The program displays a question with options.
2. The user selects an answer.
3. The program checks whether the answer is correct.
4. The final score is displayed at the end.

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Run the file:

python quiz_v1.py
